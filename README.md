# Company_Visitor

A PHP-based web application for managing and approving visitor entry requests. It features an admin panel to accept or reject visits.

#Features

- Visitor entry request form
- Admin dashboard to view pending requests
- Accept/Reject functionality with custom message
- Status updates stored in MySQL database
- User-friendly interface with basic HTML and JavaScript

#Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
